# SkyflowFoundry Directory and Demo Site

Welcome to the SkyflowFoundry Directory and Demo Site.

This project contains a web app (React + Vite) designed to be a directory of public SkyflowFoundry projects (github.com/skyflowfoundry) with a nice paginated, filterable, and searchable UX.
